server_construct

server *server_construct(short unsigned int domain, int service,
	int protocol, short unsigned int port, int backlog,
	uint32_t interface);

Allocates a server, creates the socket, sets SO_REUSEADDR, bind(), and listen().

parameters

domain
Address family (e.g. AF_INET).
service
Socket type (e.g. SOCK_STREAM).
protocol
Protocol (0 for default TCP).
port
Host port; stored with htons().
backlog
listen() backlog.
interface
Bind address as uint32_t (e.g. INADDR_ANY via htonl).

returns

Pointer to server on success. Calls exit() on fatal socket errors.

Used internally by http_construct with AF_INET, SOCK_STREAM, backlog 255.
