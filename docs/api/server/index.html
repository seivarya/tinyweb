server engine api

the core routing, threading, and parsing modules of the server.

void register_static_dir(http *srv, const char *dir_path)

configures the global static file directory. the server will automatically intercept any unregistered routes and serve files from this directory instead.

void register_route(...)

binds a dynamic route_func to a specific uri. requests hitting this uri will be passed to your custom c function for dynamic processing.

char* render_func(const char *status, int file_count, ...)

a variadic utility that reads multiple files from the disk, stitches them together, and constructs a completely valid http response string ready for dispatch.

request *request_construct(char *req_str)

the heart of the http parser. safely tokenizes raw socket strings into structured dictionaries containing headers, methods, and the request uri.

executor *exec_create(size_t num_threads)

initializes a dynamic threadpool to process incoming socket connections concurrently without blocking the main execution loop.
