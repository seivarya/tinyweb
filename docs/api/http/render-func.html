render_func

char *render_func(const char *status, int file_count, ...);

Concatenates HTML files and builds a complete HTTP/1.1 response.

parameters

status
Status text after "HTTP/1.1 " (e.g. "200 OK").
file_count
Number of file path arguments.
...
char * paths to read and stitch as body.

returns

Malloc'd response string; caller must free.

Always sets Content-Type text/html and Connection keep-alive.
