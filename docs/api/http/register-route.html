register_route

void register_route(http *srv,
	char *(*route_func)(http *srv, request *req),
	char *uri, int count_methods, ...);

Registers a URI handler. Varargs are count_methods int values (parser method enums).

parameters

srv
HTTP server.
route_func
Returns full HTTP response string or NULL for index fallback.
uri
Exact URI key (e.g. "/api").
count_methods
Number of following int method codes.
...
Method integers (GET, POST, etc.). Not enforced at dispatch yet.

returns

None.

Route stored by value in dict; only route_func pointer is live after insert.
