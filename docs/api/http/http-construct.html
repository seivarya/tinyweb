http_construct

http *http_construct(unsigned short port, size_t thread_cnt);

Builds the HTTP server: underlying server socket, route dict, default static_dir "frontend".

parameters

port
Listen port.
thread_cnt
Worker threads for executor (floored to 10 in exec_create).

returns

http pointer or NULL if malloc fails.
