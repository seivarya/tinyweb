data structures api

the custom memory-managed foundations built from scratch.

dict_insert(dict *dictionary, const char *key, const void *value, size_t size)

hashes a string key and inserts a memory-safe copy of the payload into the dictionary. automatically handles hash collisions via linked bucket chains.

void *dict_search(dict *dictionary, const char *key)

retrieves a pointer to the value stored in the dictionary. heavily utilized for blazing fast http header lookups.

void enqueue(queue *q, void *data, size_t size)

thread-safe operation to push items to the rear of the queue. used by the executor to manage pending socket connections.

void bst_insert(bst *tree, void *data, size_t size)

inserts data into a binary search tree using a custom comparator. dynamically allocates nodes and gracefully navigates left or right branches.

void slist_insert(slist *list, size_t index, void *data, size_t size)

injects a new node into a singly linked list at a specific index. guarantees o(n) traversal insertion with rigorous bounds checking.
