getting started

Build the demo server and serve this documentation tree from docs/.

build

make server

Produces server from tests/test.c and core sources. Requires gcc, pthread, POSIX sockets (Linux, macOS, or WSL).

run

./server

Listens on http://127.0.0.1:1028. Static root is docs in test.c.

urls

  • / — index.html
  • /guide/architecture.html — nested guide page
  • /api/http/register-route.html — nested API page
  • /css/style.css — stylesheet

Paths map as docs + URI. Stylesheet href is /css/style.css (not /docs/css/…).

typography

Docs use SauceCodePro NFM via font-family local names. Install the font on your system for the intended look; otherwise the browser falls back to system monospace.
