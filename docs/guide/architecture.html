tinyweb / guide / architecture

architecture

Four layers: POSIX server, http accept loop, executor workers, and parser + dict routing.

components

  • server.c — socket(), bind(), listen()
  • http.c — accept, dispatch handler, static fallback
  • executor.c — FIFO queue + pthread_cond_wait
  • parser.c — tokenize request line and headers
  • dict.c — route table and header maps

data flow

main → http_construct → register_static_dir("docs")
     → launch → accept → exec_add_work(handler)
     → read → request_construct → dict_search(routes, uri)
     → route_func | static file → write → close

See request lifecycle for per-connection detail.
